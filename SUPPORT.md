# Support

OpenConvo is maintained by one person and has no paid support. Here is where
each kind of request belongs:

- **Installation and usage questions**: read the
  [self-hosting guide](docs/self-hosting.md) and the
  [upgrade guide](docs/upgrades.md) first, then
  [open an issue](https://github.com/openconvo/openconvo/issues/new/choose)
  with your version, host details and the relevant log lines.
- **Bug reports**: use the
  [bug report form](https://github.com/openconvo/openconvo/issues/new?template=bug_report.yml).
  Remove tokens, passwords and private message content from diagnostics.
- **Feature requests**: use the
  [feature request form](https://github.com/openconvo/openconvo/issues/new?template=feature_request.yml)
  and describe the problem you hit rather than a solution.
- **Security reports**: never in a public issue. Follow
  [SECURITY.md](SECURITY.md): GitHub private vulnerability reporting or
  security@openconvo.com.

Code contributions are not accepted; [CONTRIBUTING.md](CONTRIBUTING.md)
explains why and what helps instead.
